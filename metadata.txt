about=Annotate text labels on scanned maps for machine learning research.
    Draw each word as a polygon on a georeferenced map raster, enter its transcription and certainty, and link words into phrases.
    For every label the plugin stores cubic bezier curves of the top and bottom edge, an axis-aligned and an oriented bounding box,
    and optional statistics: altitude and slope from DEM and slope rasters, edge complexity (GRASS i.zc), contrast and the centroid in WGS 84.
    Annotations export to COCO-style JSON in image pixel coordinates (ABCNet / DeepSolo bezier format, selectable bbox format).
    The GRASS GIS provider is only needed for edge complexity. See the README for drawing rules, settings and the export format.
